# TIMEBOY ADVANCE — 스톱워치

휴대용 게임기 형태의 단일 파일 스톱워치. 랩을 측정하는 동안 픽셀 캐릭터가
사이드스크롤 스테이지를 끝없이 달립니다.

**[index.html](index.html) 파일 하나만 브라우저로 열면 됩니다.** 빌드 과정, 의존성, 외부 리소스가 전혀 없습니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| 십자키 (`방향키`) | 랩 기록 |
| **A** (`Z`, `Space`) | 시작 / 정지 / 계속 |
| **B** (`X`) | 초기화 |
| **START** (`Enter`) | A와 동일 (시작 / 정지) |
| **SELECT** (`오른쪽 Shift`) | 사운드 on / off |

화면의 버튼을 직접 클릭해도 동일하게 동작합니다.

## 구현 메모

- **시간 측정**: `performance.now()` 기준으로 경과 시간을 계산하고 `requestAnimationFrame`으로 렌더링합니다. `setInterval` 누적 오차가 없고, 백그라운드 탭에서 rAF가 멈춰도 재개 시점의 시간이 정확합니다.
- **화면**: 실제 GBA 해상도인 240×160 캔버스에 그린 뒤 `image-rendering: pixelated`로 확대합니다. HUD 문자는 코드에 내장한 5×7 픽셀 폰트로 직접 찍습니다 (웹폰트 없음).
- **스테이지**: 월드 길이 1200px를 모듈로 순환시켜 약 13초마다 이음매 없이 루프합니다. 골 지점은 없습니다. 구름 0.35배, 언덕 0.6배 패럴랙스.
- **캐릭터**: 14×16 픽셀 스프라이트, 3프레임 달리기 + 점프 프레임. 파이프를 만나면 자동으로 점프합니다.
- **시간의 순수 함수**: 스크롤 거리와 점프 높이 모두 경과 시간만으로 결정됩니다. 정지하면 장면도 그 자리에 멈추고, 계속하면 정확히 이어집니다 — 애니메이션 상태와 측정 시간이 어긋날 수 없습니다.
- **사운드**: WebAudio 스퀘어파로 합성한 블립. 음원 파일이 없습니다.
- **본체 UI**: CSS container query 단위(`cqw`)로 조립해 창 크기에 맞춰 기기 전체가 비율을 유지하며 확대·축소됩니다.

## 라이선스 / 자산

닌텐도의 스프라이트, 폰트, 상표를 포함하지 않습니다. 캐릭터·타일·픽셀 폰트는 모두
이 저장소를 위해 직접 그린 오리지널 픽셀 아트이며, 기기 이름 `TIMEBOY ADVANCE`도
실제 제품명이 아닙니다. 고전 플랫포머 장르의 시각적 관습만 참고했습니다.
