# TIMEBOY ADVANCE — 스톱워치

휴대용 게임기 형태의 단일 파일 스톱워치. 랩을 측정하는 동안 픽셀 캐릭터가
사이드스크롤 스테이지를 끝없이 달립니다.

**[index.html](index.html) 파일 하나만 브라우저로 열면 됩니다.** 빌드 과정, 의존성, 외부 리소스가 전혀 없습니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| 십자키 (`방향키`) | 점프 + 랩 기록 |
| **A** (`Z`, `Space`) | 시작 / 정지 / 계속 |
| **B** (`X`) | 초기화 |
| **START** (`Enter`) | A와 동일 (시작 / 정지) |
| **SELECT** (`오른쪽 Shift`) | 사운드 on / off |

십자키는 십자 모양 버튼 하나이며, 네 방향과 **중앙** 어디를 눌러도 같은 동작을 합니다.
방향키 4개는 모두 이 버튼에 매핑됩니다.

화면의 버튼을 직접 클릭해도 동일하게 동작합니다.

### 스테이지 상호작용

점프해서 **상승 중에** 머리로 블록 밑면을 치면 반응합니다 (마리오와 같은 조건 —
내려오는 중이거나 옆에서 닿는 건 판정되지 않습니다).

| 대상 | 결과 |
| --- | --- |
| 일반 벽돌 | 부서지고 조각 4개가 튀어 흩어집니다 |
| **?** 상자 | 동전이 튀어올라 사라지고 `200` 이 떠오릅니다. 상자는 빈 상자로 바뀌고 HUD 동전 수가 1 올라갑니다 |
| 빈 상자 (이미 비운 **?**) | 여전히 단단해서 막힙니다. 소리만 나고 보상은 없습니다 |
| 부서진 벽돌 자리 | 비어 있으므로 그대로 지나갑니다 |

**블록은 천장입니다.** 부딪히면 캐릭터 머리가 블록 밑면에 딱 붙어 상승이 멈추고,
그 자리에서 곧장 떨어집니다 — 블록보다 위로는 올라가지 않습니다. 일찍 착지한
만큼 곧바로 다시 뛸 수 있습니다. 머리 위가 비어 있으면 점프는 원래 높이(46px)를
그대로 냅니다.

스테이지가 1200px마다 순환하므로, 한 바퀴(약 13초)를 돌면 부순 블록도 원래대로
돌아옵니다. 초기화(**B**)하면 즉시 원복됩니다.

## 구현 메모

- **시간 측정**: `performance.now()` 기준으로 경과 시간을 계산하고 `requestAnimationFrame`으로 렌더링합니다. `setInterval` 누적 오차가 없고, 백그라운드 탭에서 rAF가 멈춰도 재개 시점의 시간이 정확합니다.
- **화면**: 실제 GBA 해상도인 240×160 캔버스에 그린 뒤 `image-rendering: pixelated`로 확대합니다. HUD 문자는 코드에 내장한 5×7 픽셀 폰트로 직접 찍습니다 (웹폰트 없음).
- **스테이지**: 월드 길이 1200px를 모듈로 순환시켜 약 13초마다 이음매 없이 루프합니다. 골 지점은 없습니다. 구름 0.35배, 언덕 0.6배 패럴랙스.
- **캐릭터**: 14×16 픽셀 스프라이트, 3프레임 달리기 + 점프 프레임. 파이프를 만나면 자동으로 점프하고, 십자키를 누르면 그 자리에서 점프합니다(공중에서는 재점프 없음). 두 점프가 겹치면 더 높은 쪽을 씁니다.
- **블록 상호작용**: 맞은 블록을 `"루프 회차:줄:칸"` 키로 기억합니다. 판정은 캐릭터 상단이 블록 밑면을 *상승 중에 통과하려 한* 프레임에만 성립하고, 겹친 면적이 가장 큰 칸 하나에만 부딪힙니다. 다시 그려질 일이 없는 회차는 버려 메모리가 늘지 않습니다.
- **부딪힘(bonk)**: 부딪힌 프레임에 머리를 블록 밑면 좌표로 고정해 파고드는 것을 막고, 그 시각(`bonkAt`)과 높이(`bonkY`)를 기록합니다. 이후 궤적은 포물선 점프 대신 `bonkY + g·t²` 낙하로 바뀝니다. 속도를 프레임마다 누적하는 시뮬레이션이 아니라 *기록된 시각에 대한 닫힌 식*이라, 아래의 "시간의 순수 함수" 성질이 그대로 유지됩니다 — 부딪혀 떨어지는 중에 정지하면 캐릭터가 그 높이에 그대로 얼어붙습니다.
- **시간의 순수 함수**: 스크롤 거리, 점프 높이, 벽돌 파편과 동전의 궤적이 모두 경과 시간만으로 결정됩니다. 십자키 점프도 벽시계가 아니라 누른 시점의 *경과 측정 시간*을 기록해 높이를 계산하고, 블록을 맞은 시각도 같은 기준으로 저장합니다. 그래서 정지하면 캐릭터는 공중에서, 파편과 동전도 뜬 자리에서 그대로 멈추고, 계속하면 남은 궤적을 정확히 이어갑니다 — 애니메이션 상태와 측정 시간이 어긋날 수 없습니다. 유일한 예외는 "어떤 블록이 맞았는지"와 "어디서 부딪혔는지"라는 상태인데, 둘 다 정지 중에는 바뀌지 않고 초기화하면 사라집니다.
- **사운드**: WebAudio 스퀘어파로 합성한 블립. 음원 파일이 없습니다.
- **본체 UI**: CSS container query 단위(`cqw`)로 조립해 창 크기에 맞춰 기기 전체가 비율을 유지하며 확대·축소됩니다.

## 라이선스 / 자산

닌텐도의 스프라이트, 폰트, 상표를 포함하지 않습니다. 캐릭터·타일·픽셀 폰트는 모두
이 저장소를 위해 직접 그린 오리지널 픽셀 아트이며, 기기 이름 `TIMEBOY ADVANCE`도
실제 제품명이 아닙니다. 고전 플랫포머 장르의 시각적 관습만 참고했습니다.
